# 사장님앱 통계 프로토타입 v3

`작업계획서_v3_IA개편_다점포계정.md` 기준 클릭 프로토타입입니다. v1(`stats-prototype`), v2(`stats-prototype-v2`)와는 완전히 분리된 별도 프로젝트입니다.

## 실행

```bash
cd stats-prototype-v3
npm install
npm run dev
```

## 구성

- **홈** = 사장님앱 통합 메인화면. 탭 없이 항상 "오늘" 기준 실시간 대시보드
  1. 일간 매출 누적 (전일 대비 · 지역 평균 대비)
  2. 일간 주문건수 누적 (전일 대비 · 지역 평균 대비)
  3. 일간 객단가 누적 (전일 대비 · 지역 평균 대비)
  4. 주간 매출 누적 막대 그래프 + 요일별 매출·객단가 스트립 (아직 도래하지 않은 요일은 막대 없음)
  5. 주간 시간대별 주문건수
  6. 최근 30일 매출 - 포인트 연관/딜리버리 연관 매출 비중을 독립 막대(meter) 2개로 각각 표시 + 상세분석 진입 링크
     (두 비중은 배달 주문 내 포인트 적립·사용 등으로 중첩될 수 있어 합이 100%를 의미하지 않는다는 안내 문구 포함)
  - "날짜별 보기" 진입점을 통해 기존 일간/주간/월간 탭 + 화살표 날짜이동 화면(과거 데이터 드릴다운)으로 별도 진입
- **좌측 햄버거 메뉴** → 9개 상위메뉴 드로어 (모바일 프레임 안에서만 슬라이드)
  - 홈 / 주문관리 / 상품관리(품절처리) / 정산(4개 하위) / 우리매장 매출·고객분석(멤버십 고객 분석, 딜리버리 고객 분석) / 매장관리 / 우리매장 마케팅(2개 하위) / 공지사항 / 설정
  - 정산·마케팅 등 상세 미정 메뉴는 플레이스홀더 화면
- **우측 상단 프로필 아이콘** → 다점포 계정 스왑 바텀시트 (인증 화면 없이 탭 한 번으로 매장 전환)
- 각 차트 우상단 식별자 배지를 클릭하면 우측 지표 표에서 해당 행이 강조되고 나머지는 흐려짐
