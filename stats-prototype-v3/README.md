# 사장님앱 통계 프로토타입 v3

`작업계획서_v3_IA개편_다점포계정.md` 기준 클릭 프로토타입입니다. v1(`stats-prototype`), v2(`stats-prototype-v2`)와는 완전히 분리된 별도 프로젝트입니다.

## 실행

```bash
cd stats-prototype-v3
npm install
npm run dev
```

## 구성

- **홈** = 사장님앱 통합 메인화면. 탭 없이 항상 "오늘" 기준 실시간 대시보드
  1. 일간 매출 누적 (전일 대비 · 지역 평균 대비)
  2. 일간 주문건수 누적 (전일 대비 · 지역 평균 대비)
  3. 일간 객단가 누적 (전일 대비 · 지역 평균 대비)
  4. 주간 매출 누적 막대 그래프 + 요일별 매출·객단가 스트립 (아직 도래하지 않은 요일은 막대 없음)
  5. 주간 시간대별 주문건수
  6. 최근 30일 매출 - 포인트 연관/딜리버리 연관 매출 비중을 독립 막대(meter) 2개로 각각 표시 + 상세분석 진입 링크
     (두 비중은 배달 주문 내 포인트 적립·사용 등으로 중첩될 수 있어 합이 100%를 의미하지 않는다는 안내 문구 포함)
  - "날짜별 보기" 진입점을 통해 기존 일간/주간/월간 탭 + 화살표 날짜이동 화면(과거 데이터 드릴다운)으로 별도 진입
- **좌측 햄버거 메뉴** → 9개 상위메뉴 드로어 (모바일 프레임 안에서만 슬라이드)
  - 홈 / 주문관리 / 상품관리(품절처리) / 정산(4개 하위) / 우리매장 매출·고객분석(멤버십 고객 분석, 딜리버리 고객 분석) / 매장관리 / 우리매장 마케팅(2개 하위) / 공지사항 / 설정
  - 정산·마케팅 등 상세 미정 메뉴는 플레이스홀더 화면
- **로그인** — 앱 최초 진입 시 ID/PW 입력 → 휴대폰 점유인증(OTP 6자리) 2단계. 매장 계정은 자체가입이 아니라 매장당 1개씩 본사에서 발급하는 형태를 가정
  - 점유인증 화면에는 약관 동의 체크리스트(서비스 이용약관 동의·만 14세 이상 사용자 동의는 필수 체크, [안내] 개인정보 수집 및 이용사항은 동의 대상이 아닌 안내 전용)가 함께 노출되며, 각 항목은 목록+상세(펼치기)로 확인 가능. 필수 2개를 체크해야 인증 버튼이 활성화됨
  - **같은 휴대폰번호로 등록된 매장은 로그인 한 번으로 전부 계정 목록에 함께 열림** (Instagram류 다점포 스왑의 핵심 컨셉) — 데모: `gangnam2024`로 로그인하면 같은 번호를 쓰는 홍대점까지 자동으로 딸려 들어옴
  - 로그인 성공 시 "{지점명}으로 로그인되었어요." 토스트가 잠깐 노출됨
  - 데모 계정: `gangnam2024` / `pass1234` (OTP `123456`, 홍대점과 번호 공유) · `hongdae2024` / `pass1234` (OTP `123456`) · `bundang2024` / `pass1234` (OTP `654321`, 계정 추가 시연용— 다른 번호)
- **우측 상단 프로필 아이콘** → 다점포 계정 스왑 바텀시트
  - 보유 매장을 탭 한 번으로 전환 (재인증 없음, Instagram 계정 전환 참고)
  - 매장별 당일 실시간 매출(10분 간격 갱신, 원 단위)과 상단 합계(SUM) 노출
  - "+ 계정 추가"로 로그인 상태에서 다른 매장 계정을 추가 (ID/PW + 휴대폰 점유인증 필요). 성공 시 모달이 "계정 추가 성공" 화면으로 전환되고, 확인을 눌러야 닫히며 목록/SUM에 즉시 반영됨
- **지표 데이터 목록** — 로그인 직후에는 숨겨져 있고, 프로토타입(모바일 프레임) 우상단의 "데이터 목록 열기" 버튼을 눌러야 노출됨. 한 번 열리면 계속 열린 상태로 유지
- 각 차트 우상단 식별자 배지를 클릭하면 우측 지표 표에서 해당 행이 강조되고 나머지는 흐려짐
